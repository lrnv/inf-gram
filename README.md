# INF-GRAM — Machine Learning for Healthcare

This repository contains the student material for the **INF-GRAM** course.

Course material is published progressively throughout the semester. Practical
work, corrections and the final project are released according to the course
schedule.

Links to the online sessions and administrative information are available on
Amétice.

## Course outline

The course is organized around the following topics:

1. **Landscape of machine learning for healthcare**
2. **Supervised learning**
3. **Decision trees**
4. **Ensemble learning**
5. **Classifier evaluation**
6. **Final project**

## Getting the course material

Clone the repository with:

```bash
git clone https://github.com/lrnv/inf-gram.git
```

To update an existing local copy:

```bash
git pull
```

## Working environment

The course uses **Python**, Jupyter notebooks and standard machine-learning
libraries. VS Code with the Python and Jupyter extensions is a suitable setup.

Required packages and datasets are specified in the relevant course material.

## Publication of material

Lecture notes and practical work are published progressively. Partial corrections
or additional resources may be released after the corresponding sessions.
